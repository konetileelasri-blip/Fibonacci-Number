Fibonacci Number

📌 Problem

The Fibonacci numbers form a sequence where each number is the sum of the two preceding numbers.

Given an integer "n", return the "n"th Fibonacci number.

💡 Example

Input: n = 4
Output: 3

Explanation

The Fibonacci sequence is:

"0, 1, 1, 2, 3, 5, 8..."

Therefore, the 4th Fibonacci number is "3".

💻 Language

Java

📂 File

"FibonacciNumber.java"

🧠 Approach

1. Handle the cases "n = 0" and "n = 1".
2. Initialize two variables with "0" and "1".
3. Use a loop to calculate the next Fibonacci number.
4. Update the previous two values.
5. Return the final value.

⏱️ Complexity

- Time Complexity: O(n)
- Space Complexity: O(1)

🎯 Goal

To practice loops and basic dynamic programming concepts using Java.
